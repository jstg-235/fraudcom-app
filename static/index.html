Presets

A preset saves your inputs, groups, colors, and hot words — one per event. The last one you use auto-loads on launch.

Setup templates

Move a whole setup between computers: inputs, groups, colors, hot words, corrections and (optionally) automations. Import also reads .pcconfig show files. Inputs are matched to the audio devices on this computer by name.

Roster backups

Your inputs and groups are auto-saved to disk on every change, with a running history. If a roster ever disappears, restore it here.

Automations

When a phrase is heard on a channel — or an OSC message arrives — send an OSC cue (UDP or TCP) to lighting desks, media servers or QLab, switch things on a Yamaha RIVAGE or DiGiCo console, send MIDI, or flash a message on screen. E.g. say “black out” and fire a cue.

OSC input (show control)

Commands are addressed /fraudcom/… (see the reference below). Point cues at this computer and port. Automatic uses 9000; if another app already holds 9000, FraudCom takes 9765 and shows it here.
Command reference
ping · versionreplies …/pong · …/version/reply (the version)
channel/count · channel/listreplies at the same address + /reply: the count, or one reply per channel (number, slug, name)
channel/ch/namereplies (slug, name)
channel/next · channel/previous · channel/ch/selectshows that channel on its own
channel/ch/send textadds a line from that channel
channel/ch/clear · …/markclears its lines · marks them read
scroll/up · down · currentscrolls the feed
font/increase · decreasetext size
window/show · hideshows or hides the window
flash text [seconds] [repeats] [color]full-screen message; color is a name (red, amber, green, cyan, blue, purple, magenta, pink, orange, yellow, lime, teal, white, gray, black) or #rrggbb
automation/trigger name · automation/name/triggerruns an automation
automation/count · list · name/namereplies like the channel queries
marker [text] · note textFraudCom: into the feed and transcript
mute ch [1|0] · unmute chFraudCom: stop / resume transcribing
start · stopFraudCom: listening on / off
ch is a channel's number (1 = top of the inputs list), its name, or its name with hyphens for spaces (stage-left) — or all, or selected. Replies go back to the sender, over the same transport.

Remote API

A REST + WebSocket API under /api/v1 for show-control software: status, channels, groups, keywords, automations (including webhooks), configurations (your presets), the live transcript (with streaming), window, flash and OSC control. MIDI isn't part of FraudCom: MIDI lists are empty and MIDI sends answer “not implemented”. Keywords are FraudCom's hot words and jargon corrections, and apply to every channel.

Speech recognition

Fixes spelling of trade terms, e.g. f o h => FOH. Hot words apply as you add them.
