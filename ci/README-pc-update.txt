FraudCom {VER} - Windows update (app only)
==========================================
For an existing FraudCom install.

1. Close FraudCom.
2. Unzip. You get an 'app' folder.
3. Replace your existing FraudCom\app folder with it.
4. Run FraudCom\app\FraudCom.exe.

Your models, inputs, presets and settings are untouched.
